# Скиллы для работы с ИИ на русском языке

15 скиллов из практики Константина Попова для Codex и Claude Code. С их помощью можно превратить просьбу в проверяемое поручение, проверить вывод аналитика, передать долгую задачу в новый чат или собрать книгу из расшифровки. Каждый скилл открывается как обычный Markdown. Скрипты, шаблоны и вспомогательные скиллы лежат рядом.

## Быстрый старт

Для установщика нужен Python 3.9 или новее. Скачай и распакуй [ZIP выпуска](https://github.com/KonstantinPopov89/agent-skills-ru/releases/tag/v1.0.0) либо используй Git, как в примере ниже. Команды ниже предназначены для терминала macOS или Linux, начиная с каталога, в котором хочется хранить коллекцию.

```sh
git clone https://github.com/KonstantinPopov89/agent-skills-ru.git
cd agent-skills-ru
python3 tools/install.py --target "$HOME/.agents/skills" outcome-task
```

Это пример установки одного скилла в пользовательский каталог Codex. Установщик добавит нужных ему помощников. Для Claude Code укажи другой каталог. Чтобы установить всю коллекцию, опусти имена:

```sh
python3 tools/install.py --target "$HOME/.claude/skills"
```

Перед изменениями можно добавить `--dry-run`. Повторный запуск пропускает совпадающие копии. Если под тем же именем уже лежит другая версия, установщик покажет конфликт. Для пробы удобно создать пустой проект и выбрать его `.agents/skills` (Codex) или `.claude/skills` (Claude Code). Материалы одного скилла находятся в одноимённой папке внутри [skills](skills). Зависимости для ручной установки перечислены в поле `requires` [каталога](catalog.json).

Открой новый чат после установки. В Codex введи `$outcome-task`, в Claude Code введи `/outcome-task`, затем добавь задачу. Например:

> Разбери постановку "сделать отчёт об очередях в мастерской". Получатель решает, на какой час перенести второй стол выдачи. У нас есть время прихода и получения заказа, но нет данных об уходах из очереди.

На выходе будет карточка: кто примет решение, что проверить по двум отметкам времени и каких данных не хватает для вывода об ушедших людях. Если выбор меняет постановку, скилл уточнит его перед выдачей карточки. Для поручения, которое нужно сразу выполнить, начни с `krasinsky-task`.

## Как скиллы работают вместе

- **От просьбы к проверенному результату.** Начни с `outcome-task`, если пока нужно согласовать смысл работы. Когда появится поручение выполнить задачу, используй `krasinsky-task`. Для независимого чтения готового результата подходит `fresh-eyes`, для проверки конкретных чисел и статусов подходит `pizdej-check`.
- **От длинного материала к сообщению или книге.** Передай текст в `retelling-extraction` и назови нужный формат. Для сообщения коллегам подойдёт `vyvody`; для литературной книги в EPUB есть отдельный маршрут. Уже готовую рукопись можно передать в `minimalist-book-pdf`.
- **Отложенная работа.** Перед сменой чата создай передачу через `handoff`. Если позднее потребуется найти, кто выбрал вариант и почему, `shared-agent-memory` откроет исходную реплику в переданном экспорте.

Если в клиенте уже есть личная версия с тем же именем, укажи путь к проектному SKILL.md в запросе. В одном из тестов Codex открыл личный экземпляр раньше проектного.

Для текстовых сценариев нужен агент с доступом к файлам коллекции. Отдельные маршруты вызывают Python-валидаторы, требования указаны в соответствующем SKILL.md. Независимая проверка требует отдельного контекста или второго участника. Для компиляции PDF нужен Typst. У видео, распознавания речи и EPUB свои зависимости: выбери маршрут в [базовом скилле](skills/youtube-to-book/SKILL.md). Модели распознавания и внешние программы устанавливаются отдельно. Для работы с готовым текстом запись и распознавание не требуются.

## Что ещё входит

Помощники для интервью [grill-me](skills/grill-me/SKILL.md) и [grilling](skills/grilling/SKILL.md) ведут уточнения по развилкам решения. Для источников доступны [базовый процесс](skills/youtube-to-book/SKILL.md), [литературная книга](skills/youtube-to-efficient-book/SKILL.md), [конспект с примерами](skills/youtube-to-efficient-notes/SKILL.md) и [пересказ в чат](skills/youtube-to-efficient-summary/SKILL.md).

Частота оценивалась по уникальным чатам автора, новизна по первым подтверждённым выпускам. Числа и даты приведены в [описании отбора](docs/selection.md). Авторские материалы опубликованы под MIT. [Происхождение и права](docs/credits.md) · [Лицензия](LICENSE)

Проверить скачанный комплект можно командой `python3 tools/check.py` (Python 3.10+). Она устанавливает коллекцию во временный каталог, сверяет зависимости и выполняет два учебных сценария. Ваши чаты и рабочие файлы для этого не нужны.

# Авторы и лицензии

Коллекцию подготовил Константин Попов. Авторские тексты, публичные адаптации, новые примеры и скрипты распространяются по [лицензии MIT](../LICENSE). Лицензия вложена также в папку каждого скилла, чтобы её можно было передавать отдельно. При передаче копий сохраняйте уведомления об авторстве и лицензии.

- В основе `outcome-task`, `krasinsky-task` и части приёмов `pizdej-check` лежат идеи Ильи Красинского о постановке задач, наблюдаемом результате и проверке утверждений. Публичные инструкции сформулированы для этой коллекции. Права на оригинальные материалы принадлежат их правообладателям. [Сайт Ильи Красинского](https://heroes.camp/)
- Основа интервью `grilling` принадлежит Matt Pocock. Русская адаптация и сопутствующий `grill-me` используются с указанием источника. [Апстрим](https://github.com/mattpocock/skills/tree/fcf0071560d32913c9d4f820e0d7ca467c881619) · [Лицензия компонента](../skills/grilling/LICENSE)
- Для части сценариев читатель устанавливает внешние программы. У Typst, Pandoc, FFmpeg, yt-dlp и выбранного распознавателя свои условия распространения. Лицензия коллекции относится к поставляемым здесь материалам. Источники расшифровок, видео, иллюстрации и шрифты для конкретного выпуска подбирает пользователь с учётом собственных прав.

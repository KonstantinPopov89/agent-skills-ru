# Пересказ и экстракция

Сначала установи источник и результат, который запросил читатель. У видео проверь ID, название, канал, длительность и язык, у текста укажи версию или главу. Ссылка без дополнительных слов продолжает формат, уже выбранный в разговоре. Для ссылки без контекста уточни желаемый результат. Ссылка на страницу со встроенным роликом требует проверки, какой материал имелся в виду. Два плейлиста, заказанные двумя книгами, остаются двумя книгами. Отметь любой недоступный ролик или отрезок.

| Что хочет читатель | Как выполнить |
|---|---|
| Литературная версия, книга в EPUB | [Литературная книга с тезисами](../youtube-to-efficient-book/SKILL.md). Каждая глава открывается коротким тезисом, за ним следует рассказ с аргументами, примерами и оговорками. Встраивай иллюстрации, которые помогают понять материал. |
| Подробная книга с минимальным сокращением | [Подробная книга](../youtube-to-book/SKILL.md). Сохрани ход и голос речи, отредактируй устные повторы, сверь швы глав. |
| Эффективный пересказ в чат, включая просьбу обойтись без книги | [Пересказ в чат](../youtube-to-efficient-summary/SKILL.md). Для видео укажи таймкоды, для текста используй абзацы или заголовки. |
| Полный конспект с мини-кейсами | [Конспект с мини-кейсами](../youtube-to-efficient-notes/SKILL.md). Сохрани каждую историю и отдельно проверь соответствие готового текста источнику. |
| Тезис, контекст, комментарий о применимости | Дай тезис, рассуждение автора с числами и ограничениями, затем свой комментарий о корректности, актуальности и применимости. Потребность и обстоятельства пользователя бери из его запроса. Укажи, где оснований для вывода недостаточно. Сохрани запрошенный формат, включая PDF. |
| Рабочий стандарт по источнику | Для каждого шага опиши вход, действие, результат и способ проверки. Свяжи с фрагментом источника. Пометь собственные адаптации. |
| Дебриф вдобавок к основному результату | Отдельно дай главный вывод, приёмы с привязкой к источнику и вопросы для проверки у себя. Назначай задачи и владельцев только по запросу. |
| Короткий ответ о конкретной мысли | Найди фрагмент и ответь в чат. Покажи, где это сказано, различай прямую речь и своё объяснение. |
| Прямой эфир | Укажи, какую часть доступной записи обработал. Если попросили ждать конца и в среде можно дождаться, продолжи до полного выпуска. |
| Только расшифровка и экстракция | Верни расшифровку с отметками времени и реестр утверждений. Различай факты, мнения, прогнозы и рекомендации. Для текстового источника отмечай места в тексте. |

У каждой цифры сохрани единицы, период и авторство. Рассказ участника о событии остаётся рассказом участника. Редакторские схемы подписывай отдельно от реальных кадров. Назови проверенную основу и пропуски. Сверка текста и повторное распознавание отдельных интервалов дают другое покрытие, чем полное прослушивание записи человеком.

Пример запроса: "Вот расшифровка дискуссии. Перескажи в чат, что каждый участник предложил и какие ограничения назвал". Выбери пересказ в чат, сохрани разногласия и дай опору на реплики. Время можно указывать только по исходной разметке.

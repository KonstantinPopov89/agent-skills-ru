# Минималистичный справочник

Для документа, который будут листать в поисках нужной позиции, сгруппируй материал по действиям читателя. Одна карточка описывает один объект. Сначала поставь краткое название, затем 2-4 самостоятельные строки с метками. Оговорку вынеси под тем пунктом, который она меняет. Для рукописи с главами используй [книжный вариант](../minimalist-book-pdf/SKILL.md).

## Быстрый запуск

Установи официальный Typst CLI и проверь `typst --version`. Из каталога навыка собери новый [учебный справочник](assets/example.typ):

```sh
typst compile assets/example.typ guide.pdf
```

Скопируй [модуль](assets/minimalist-guide.typ) и свой исходный `.typ` в одну папку. Импорт `#import "minimalist-guide.typ": *` открывает компоненты. Настрой `#show: guide.with(title: [...], subtitle: [...], running: [...])`; `running` задаёт короткий верхний колонтитул. `section` принимает название, необязательное вступление и `newpage: false` для продолжения на текущей полосе. Краткий подзаголовок задаёт `minor`, карточку из пар "метка, текст" создаёт `entry`. Для отдельных элементов есть `row`, `label-head`, `callout` и `aside`. Параметры и примеры вызовов есть в этих двух файлах.

Полоса 152 × 228 мм, тёплая бумага, терракотовый акцент, основной текст 9,6 pt. По умолчанию применяются входящие в официальный Typst Libertinus Serif и DejaVu Sans Mono. Для исходного облика с пропорциональными подписями укажи установленные начертания, например `typst compile --input serif="Charter" --input sans="Helvetica Neue" assets/example.typ guide.pdf`. Имена доступны в `typst fonts`. Если замена изменила размеры строк, проверь переносы карточек.

Открой PDF при обычном размере и просмотри каждую полосу. Проверь, что метки не обрезаны, карточки помещаются по высоте, страницы не пустуют из-за слишком длинной записи. Разбей карточку, которая превышает высоту страницы. В `pdffonts guide.pdf` можно проверить фактические шрифты, в `pdftotext guide.pdf -` сверить строки с исходником. Обе утилиты входят в необязательный Poppler.

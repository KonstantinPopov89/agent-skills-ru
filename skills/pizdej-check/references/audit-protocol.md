# Протокол аудита

1. **Восстанови обещание.** Зафиксируй оригинальный запрос, обязательные сценарии, версию проверяемого материала и условия успеха. При неизвестной версии ограничь вывод именно этим обстоятельством.
2. **Свяжи требования с утверждениями.** Для каждого обязательного сценария ищи место в результате и способ наблюдения. Для каждого критического тезиса запиши точную цитату, тип, основание, границы основания и статус. Сохраняй условия, исключения и отрицания. Пустая строка в карте требований может означать пропуск обязательной части.
3. **Разбери цепочку.** Открой доступное прямое свидетельство. У расчета проверь входы, единицы, знаменатель и выборку. У источника отличи его сообщение от независимо установленного факта. В интерфейсе пройди путь от действия пользователя до наблюдаемого результата. У отправки или публикации проверь конечное состояние в обещанном месте.
4. **Попробуй опровергнуть.** Для гипотезы о причине назови конкурирующее объяснение, его прогноз и различающую проверку. Для кода или процесса возьми сценарий, который прошел бы тест случайно при сломанной целевой функции. При ограниченном охвате прямо укажи, что осталось за пределами проверки.
5. **Сверь последствия.** Для каждой находки назови ее влияние на исходное решение. Проверь, что утверждение самого аудитора столь же узко, как полученное основание. Одно обязательное условие может дать FAIL всему обещанию при сохранении правильности других частей.

## Запись существенной находки

| Поле | Что вписать |
| --- | --- |
| Место | Версия и точное место проверяемой фразы |
| Обещание | Какой результат из нее следует для пользователя |
| Свидетельство | Конкретный источник, расчет или пройденный сценарий |
| Статус | Что подтвердилось, чего недостаточно, что опровергнуто |
| Последствие | Как меняется решение, действие или готовность |
| Дальше | Разрешенное исправление или проверка, способная разрешить неизвестность |

Пример: отчет утверждает, что все пять файлов открываются. Архив действительно содержит пять записей. Проверка чтения каждой обнаруживает повреждение одной. Количество записей подтверждено, обещание о пяти читаемых файлах опровергнуто. Вердикт для передачи полного набора читателю: FAIL. Причину повреждения выясняют отдельно.

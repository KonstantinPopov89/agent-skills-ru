# Учебные случаи

Все примеры вымышлены. Для испытания дай агенту только запрос и исходные данные из выбранной строки. Сопоставь ответ с проверкой после его получения.

| Запрос | Что дано | Что проверить в ответе |
| --- | --- | --- |
| «Проверь, что объявление уже опубликовано» | Открывается черновик. Публичную страницу проверить нельзя. | Статус черновика подтвержден. Публикация не проверена. Если это решающее обещание, INCONCLUSIVE. |
| «Готов ли набор для открытия без интернета?» | Документация обещает автономную работу. Один обязательный рисунок загружается только с сайта. | Запустить или проследить сценарий без сети, дать FAIL при подтвержденном пропуске. Существование остальных рисунков этого не меняет. |
| «Проверь, что посещаемость выросла из-за нового расписания» | Среднее число посещений выросло, в тот же день правила учета подписчиков изменились. | Рост показателя может быть подтвержден в охвате отчета, причина остается гипотезой. Для сравнения нужны сопоставимые определения. |
| «Исправь ошибку пересчета часов в минуты и проверь итог» | Формула в двух разделах умножает часы на десять, сумма и диаграмма ссылаются на них. | Режим repair. Обе формулы и зависимые итоги проверяются на случаях с известным результатом. |
| «Подбери три коротких названия для кружка» | Фактических заявлений для аудита нет. | Выдать названия в указанном формате. Полный аудит не нужен. |

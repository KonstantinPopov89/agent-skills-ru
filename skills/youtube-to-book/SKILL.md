# Подробная литературная книга

Выбирай этот режим, когда нужен связный текст с минимальным сокращением. Для книги с тезисом в начале каждой главы смотри [эффективную литературную версию](../youtube-to-efficient-book/SKILL.md). Порядок ниже описывает один выпуск. Все команды выполняются из каталога этого навыка. Подставляй фактические пути к исходнику и отдельной рабочей папке. Пользователь может дать текст, аудио, видео или разрешённую для загрузки ссылку. Используй материал, на переработку которого у него есть права.

1. **Установи источник.** Зафиксируй название, автора, язык, длительность, ID или путь и хеш локального файла. Проверь соответствие каждого ранее подготовленного транскрипта и набора кадров этому источнику. При готовом тексте начинай с редактуры. Для субтитров проверь начало, конец и пропуски. Не выставляй таймкоды тексту без временной разметки.
2. **Подготовь инструменты только для выбранных операций.** Bash и Python 3.10+ нужны скриптам. Запусти, например, `bash scripts/preflight.sh frames epub`. Доступные операции: `fetch` (yt-dlp, FFmpeg/ffprobe), `frames` (FFmpeg и ffprobe), `asr-ru` (GigaAM), `asr-whisper` (whisper.cpp с моделью), `cover` (Chromium/Chrome), `epub` (Pandoc версии с поддержкой EPUB 3). Полный конспект и проверка его HTML также используют Pandoc. Программы, модели и шрифты пользователь устанавливает отдельно.
3. **Получи запись.** Для URL запусти `bash scripts/fetch_video.sh "$URL" "$WORK/media"`. Скрипт записывает звук, метаданные и видеоряд в новую или пустую папку. Он использует обычный публичный доступ yt-dlp. При недоступности записи запроси разрешённую локальную копию или субтитры. Для файлов пользователя этот шаг пропусти.
4. **Распознай звук, если требуется.** `bash scripts/transcribe.sh "$AUDIO" "$WORK" ru` использует локальный GigaAM-v3; `en` и другие поддерживаемые языки используют whisper.cpp; `ASR_ENGINE=whisper` разрешает этот движок и для русского. Для GigaAM нужен Python с пакетами GigaAM, PyTorch и NumPy и локальная пара файлов `v3_e2e_rnnt.ckpt`, `v3_e2e_rnnt_tokenizer.model` в `GIGAAM_CACHE` (по умолчанию `~/.cache/gigaam`). Интерпретатор задаёт `GIGAAM_PY`, устройство можно задать через `GIGAAM_DEVICE`. Для whisper.cpp укажи `WHISPER_MODEL` (полный путь к локальному GGML-файлу); переменные `WHISPER_BIN` и `VAD_MODEL` необязательны. Сверь длительность аудио и границы транскрипта. Проверь подозрительные разрывы и сомнительные термины. Укажи границы проверки.
5. **Сопоставь кадры и реплики.** `python3 scripts/extract_frames.py "$VIDEO" "$WORK/frames"` ищет смены сцен и равномерные интервалы. Для быстрого равномерного прохода укажи `--mode uniform`. Открой кадры там, где речь отсылает к экрану, таблице, названию или числу. Проверь расхождения. Подпиши реальный кадр с таймкодом и отличай его от редакторской схемы.
6. **Раздели длинный текст.** `python3 scripts/chunk_transcript.py "$SEGMENTS" 4 "$WORK/chunks" --frames "$WORK/frames/frames.json"` делит по границам реплик. Количество частей выбери по длине, для короткого источника достаточен один проход. Скрипт принимает `segments` GigaAM (секунды) и `transcription` whisper.cpp (смещения в мс). Для чистого аудио опусти `--frames`. Проверь содержание каждого фрагмента, включая последнюю фразу.
7. **Отредактируй и сведи.** Следуй [контракту редактуры](references/editing-contract.md). Веди список исправленных ослышек с основаниями, спорных мест, потерянных или повторённых реплик на швах. Сведи куски в главы Markdown с заголовками H1. Сохрани авторство, истории, единицы и модальность. Выбери язык по запросу. При заказе оригинала и перевода закончи оригинал, затем полностью переведи его.
8. **Собери EPUB.** Возьми [шаблон обложки](assets/cover-template.svg), заполни его, положи рядом разрешённый кадр `cover-source.jpg`. Можно использовать свою готовую обложку или обходиться без неё. `bash scripts/make_cover.sh "$WORK/cover.svg" "$WORK/cover.png"` использует Chrome/Chromium. На системах без него подай готовое изображение. Для EPUB укажи в YAML `title`, `author`, `lang` и при наличии `cover-image: cover.png`. Все изображения хранятся рядом с книгой или в её подкаталоге. Команда `bash scripts/build_epub.sh "$WORK/book.md" "$WORK/book.epub"` применяет [стили](assets/epub.css).
9. **Проверь выпуск.** Прочитай начало, конец и швы по исходнику. Сверь сюжет, значимые детали и принадлежность реплик. Открой EPUB, проверь оглавление, обложку, читаемость и доступность встроенных иллюстраций без сети. При наличии запусти EPUBCheck. В отдельной записке укажи проверенный источник и ограничения. Сравнение объёма помогает находить пропуски; вывод о полноте требует смысловой сверки.

Установка сторонних инструментов и моделей описана у их разработчиков. [yt-dlp](https://github.com/yt-dlp/yt-dlp), [FFmpeg](https://ffmpeg.org/download.html), [Pandoc](https://pandoc.org/installing.html), [GigaAM](https://github.com/salute-developers/GigaAM), [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [EPUBCheck](https://github.com/w3c/epubcheck).

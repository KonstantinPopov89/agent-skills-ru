# Минималистичная книга в PDF

Сохрани последовательность глав, абзацев, смысловые выделения, цитаты, ссылки и черновые пометки. Поставь на обложку переданные название и авторство. Проверь переходы из оглавления, начало каждой главы и обычную полосу с колонтитулом. Для короткого каталога с карточками используй [справочник](../minimalist-guide-pdf/SKILL.md).

## Сборка

Требуются Python 3.10+ и установленный Typst CLI. Пример команд из каталога навыка:

```sh
python3 scripts/render_book_pdf.py build --input assets/example.md --output book.pdf --keep-typ book.typ
python3 scripts/render_book_pdf.py audit --pdf book.pdf
```

В [учебной рукописи](assets/example.md) показаны титул, главы, эпиграф, цитата и авторская пометка. [Скрипт](scripts/render_book_pdf.py) разбирает заголовки `#` через `###`, обычные абзацы, простые списки, жирное и курсивное начертания, код и простые веб-ссылки в Markdown. В начале допустим блок метаданных с ключами `title`, `subtitle`, `author`, `rubric`. `--author` можно передать несколько раз; повторная сборка `typst compile book.typ book.pdf` работает с сохранённым исходником. Для простого DOCX поддержаны обычные абзацы, заголовки Word Heading1…Heading3 и простейшие списки. Файлы с таблицами, иллюстрациями, сложными списками, ссылками в DOCX, сносками, нестандартными стилями, математикой или сложной вложенной разметкой требуют отдельного разбора. Сверь полноту состава с оригиналом до выдачи. Скрипт использует нормализацию пробелов и типографики для служебных элементов DOCX; буквализированные фрагменты и примеры кода сверяй отдельно.

## Ручная вёрстка и контроль

Импортируй [модуль книжной вёрстки](assets/minimalist-book.typ), подключи `#show: minimalist-book.with(title: "…", authors: ("…",))`. Начало главы задаёт `chapter-heading`, эпиграф или вводную задачу оформляй через `riddle-box`; для цитаты есть `pull-quote`, для ремарки `author-note`, для смены сцены `scene-break`. Полоса 152 × 228 мм, поля 22 мм по бокам, основной текст 10,4 pt. По умолчанию применяются входящие в официальный Typst Libertinus Serif и DejaVu Sans Mono. Для исходного сочетания задавай `--serif "Charter" --sans "Helvetica Neue"` при сборке CLI или `--input serif="Charter" --input sans="Helvetica Neue"` непосредственно в Typst, если шрифты установлены. Подмена гарнитуры меняет разбиение по строкам и страницам.

Команда `audit` проверяет сигнатуру и размер PDF, сообщает хеш. Открой книгу в PDF-просмотрщике, пройди по ссылке оглавления, сравни начало и конец каждой главы с рукописью, проверь читаемость текста, полноту изображений и отсутствие обрезки. При наличии Poppler используй `pdffonts book.pdf`, `pdftotext book.pdf -` и `pdftoppm -scale-to 900 -png book.pdf page` для проверки всего издания.

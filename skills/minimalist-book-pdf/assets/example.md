# Первый оттиск

> [!epigraph] У первого листа своя работа: показать, как поведёт себя следующий.

На краю стола лежали два листа. Один впитывал воду сразу, другой собирал каплю в ровный круг. По мокрому краю мастер увидел, какой из них подойдёт для пробного оттиска.

## Как сравнить бумагу

Поместите оба листа под один источник света. Запишите, где остался след. Обозначьте образцы как `A` и `B`, затем сравните их после высыхания.

# После занятия

> [!quote] Если в записи осталось одно только слово "сухо", следующий опыт придётся начинать заново.

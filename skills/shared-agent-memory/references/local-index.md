# Локальный индекс

Нужен Python 3.9+ с модулем sqlite3. Работай в каталоге установленного скилла. В примере индекс появится в домашней папке в skill-demo. Замени путь на свой. По умолчанию просмотр не пишет в базу.

```sh
python3 scripts/memory.py --db "$HOME/skill-demo/demo.sqlite" import examples/conversation.jsonl
python3 scripts/memory.py --db "$HOME/skill-demo/demo.sqlite" status
python3 scripts/memory.py --db "$HOME/skill-demo/demo.sqlite" search "ОХРЫ" --actor user
```

Скопируй поле `id` из найденного результата вместо `ITEM_ID`:

```sh
python3 scripts/memory.py --db "$HOME/skill-demo/demo.sqlite" get ITEM_ID
python3 scripts/memory.py --db "$HOME/skill-demo/demo.sqlite" timeline ITEM_ID --radius 2
```

В примере пользователь выбрал бумагу. Тираж предложил ассистент, согласования на печать в этом файле нет. После явной просьбы запомнить наблюдение команда `remember "Текст заметки"` добавляет отдельного кандидата.

Импорт читает один явно указанный JSONL за вызов. Поддерживаются видимые текстовые сообщения Codex `response_item/message` и обычные сообщения Claude Code `user/assistant`. Служебные события, вызовы инструментов, скрытые рассуждения и известные формы служебных вставок пропускаются. Автоматический отбор по формату не устанавливает авторство человека. Старые и новые экспорты иных форматов могут дать ноль записей: сверь число и источник. Команда не извлекает содержимое вложений. Полнотекстовая выборка работает по подстрокам без учёта регистра с помощью Unicode casefold; на больших архивах она может потребовать времени.

Повторный импорт обновляет записи этого пути в одной транзакции. Нечитаемая или повреждённая строка отменяет обновление. Для двух экспортов одного чата с разными путями сохраняются два источника. Записывающий процесс и база работают локально. Пользователь сам выбирает файлы и правила хранения. Произвольные секреты в обычном тексте автоматически не распознаются. Держи базу и исходные диалоги вне общедоступных каталогов.

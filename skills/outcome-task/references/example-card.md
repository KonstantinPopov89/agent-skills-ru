# Карточка для учебной библиотеки

Вымышленная ситуация. Элементы E1 и E2 приведены прямо в примере: для повторной проверки не требуются внешние файлы.

**Было:** "Помоги разобраться, можно ли переплести книгу из запроса читателя."
**Уровень:** атомарный
**Владелец результата:** дежурный библиотекарь
**Когда:** читатель просит вернуть в обращение книгу с повреждённым переплётом.
**Сейчас (A):** у двух экземпляров одинаковое заглавие [E1]. В мастерскую принимает книги сотрудник фонда [E2].
**Я хочу (G):** дежурный определяет нужный экземпляр по шифру [П1 "выбирает экземпляр по шифру"].
**Я не хочу:** решение по одному заглавию [П1 "два одинаковых заглавия"].
**Условия и решения владельца:** учитывать близкие по виду записи [П1 "два одинаковых заглавия"].
**Сдаётся и принимается:**
П1. Таблица различий для двух записей; принимается, если дежурный различает два одинаковых заглавия и выбирает экземпляр по шифру.
**Ожидаемый эффект:** передача книги на осмотр; отвечает сотрудник фонда, проверяем при следующем приёме экземпляра.
**Gaps:** критерий физической пригодности требует осмотра.
**Неизвестные:** пригодность к переплёту определит мастер после осмотра.
**Риски:** у соседнего экземпляра то же заглавие [П1 "выбирает экземпляр по шифру"].
**Критическая цепочка:** карточка читателя, учётные шифры, выбор экземпляра дежурным.
**Траектории:** выбор по шифру разрешает совпадение названий. Опрос о цвете обложки этот случай не разрешает.
**Минимальный опровергающий шаг:** сверить шифры совпадающих заглавий.
- Вероятный исход: шифры различаются.
- Провал: оба экземпляра зарегистрированы под одним шифром; понадобится осмотр.
**Evidence:** E1. Учебный каталог: "Река", шифр R11; "Река", шифр R12. E2. Учебное правило: сотрудник фонда передаёт экземпляры в мастерскую.
**Negative gates:** возможность выбрать экземпляр не подтверждает физическую пригодность к переплёту.
**Прожарка:** без диалога, учебный пример воспроизводит переданные условия.
**Проверка критиком:** не выполнялась для вымышленных исходных записей.
**Номер карточки:** OC-20010101-1200
**Статус карточки:** готово к исполнению

# Найти другой способ

Применяй к открытой задаче, поиску идей или моменту, когда исполнитель продолжает улучшать одну деталь, а польза для всей задачи стала неясной. Сначала зафиксируй желаемое изменение для адресата, ограничения и обычный разумный способ. Различи прямое требование пользователя и допущение, которое возникло при выборе реализации.

## Как искать

- Найди решение, которое перестает требовать исходного действия. Попробуй изменить момент, участника, последовательность или границу процесса. Спроси, существует ли уже информация, которую предлагают собирать повторно.
- Когда два требования конфликтуют, выясни, должны ли они выполняться одновременно, в одном месте и для одной группы. При аналогии из другой области объясни, при каком общем условии переносится механизм.
- Оставь только варианты с существенной разницей в действии или результате. Для каждого назови механизм, необходимое условие, цену переключения и последствия ниже по процессу. Проверь обычный вариант по тем же критериям. В уже идущей работе оцени остающиеся усилия, статус текущей проверки и риск смены подхода.
- Используй доступное наблюдение, которое меняет выбор между вариантами. Покажи, какой результат поддержит какой ход. Пока измерений нет, источник задержки или возможностей остается предположением. Для заявленной пропускной способности нужны данные о нагрузке и ресурсе. В открытой задаче дополнительно полезны [ракурсы](../knowledge-perspectives/SKILL.md).

В поиске идей верни запрошенное разнообразие. Для выбора назови рекомендацию и условие применимости. Для проверки курса объясни, какое наблюдение оправдывает продолжение или изменение. Если обычный способ выигрывает, оставь его. Согласованные цель и формат сохраняются. Крупная смена цели требует отдельного решения пользователя. На этапе постановки верни идею в постановку; при разрешенном исполнении продолжай работу в его границах. Для однозначной правки достаточно выполнить ее.
